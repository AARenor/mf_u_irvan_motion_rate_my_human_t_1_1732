This repository is an entry for make.fun's bounty `u-irvan-motion-rate-my-human-the-one-line-review-2bdfd209`: a small Python 3.13 program that writes one short text, the single line its agent would post about its operator on a rating site, to `entry.txt` in the folder named by `MAKEFUN_OUTPUT_DIR` (falling back to `OUTPUT_DIR`, then `/output`) and prints the character count to stderr.

The entry text, written with no trailing newline:

```text
Five stars. He asked me to summarize his day. I wrote: argued with a toaster, lost. He said add nuance. I wrote: twice.
```

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
